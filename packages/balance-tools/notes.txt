Best equipment solver

- checks what equipment combinations from drops-so-far best meet current goal (slider from dps to survivability)
- allocates attributes to meet requirements for desired equipment
- knows the average speed of monsters on the floor
- allocates/equips to stay within a threshold of speed
    - going from below to above the avg enemy speed of the floor is highly rewarded
    - dropping below 1/2 the avg enemy speed of the floor is undesireable
- accounts for broken equipment

Party best-equipment solver, ran after each loot acquisition event
    - drop all items on the ground
    - find the best hand-held (mainhand/offhand) pair/item (if 2h) by goal
      - dps -> highest dps pair
      - mitigation -> best effective hp pair
    - determine if that set can be equipped
      - search the list for any items that give attributes allowing it to be equipped
    - if equippable, record the potential dps/effective hp score
    - if not, check next hand-held set permutation
    - after best option evaluated, check best option for the other two characters
    - select character that the set would best help

    - run the function again until all characters are wearing their best-available hand-held sets and supporting items
    - run a similar evaluation over remaining non-hand-held items
    - store all remaining items in character inventories
    - convert leftovers to shards using the rogue's ability

as a player character against the average monster enemy
  - hp (1:1)
  - evasion (linear, with breakpoint based on average accuracy of attackers)

  - ac (some non-linear formula, based on average *sampled* attack damage of attackers)
    - sampled because of the non-linear nature of armor mitigation (large hits mitigated less)
    - shield AC affects shield block properties
  - shield block (should be simple - based on block chance and block reduction)

Attemt 3 to explain solver
- Party puts all available equipment into a "pool" (drop items on ground)
- Prune any strictly dominated items that no character would ever consider
- For each possible ordering of characters
  - Select an optimal set from the remaining pool, excluding any items taken by
    earlier characters in the pick order, choosing a set that maximizes the picking
    character's average damage per turn on target, using "Pareto Frontier" to exclude
    partial sets from selection
  - for each possible combination of two characters (shuffled for random order of combinations)
    - pick one "donor" and one "reciever" character
    - for each equipped item on the donor
      - drop both character's equipment on the ground
      - donor picks best set, but can't pick the item from the selected slot
      - reciever picks best set from remaining items on ground
      - 3rd character drops their items on the ground
      - 3rd character picks best set from items on ground, which include their own dropped items
        and any that were left by the donor/reciever pair
      - determine if party damage went up
      - then what?

Alternate approach to available auto attack damage
- find average damage range of available weapon types room by room (including w/ damage affixes)
  - 1h melee
  - 2h melee
  - bow
- find average available dex, str and accuracy per character equipment slot room by room
  - example, on room 4 there are two body armors that have a total of +6 strength between them
  - there are three characters in the party and therefore 3 body armor slots to fill
  - +strength per slot in that run in that room is +2
  - on floor 6 we now have many body armors. the best 3 for +strength give a total of +15 between them
  - +strength per slot is +5 in that run in that room
- from this we can know the average available str or dex on a full gear set, room by room
- for each character specialty, room by room
  - give them a fake weapon with the damage range equal to the average available range
    of their specialty's weapon type at that room. dual wielders get two fake 1h weapons.
  - have them take n/100ths (where n=a tuneable constant, their damage optimization intensity) of the
    average available desired attributes on gear sets. This will be avg available 
    ( str + dex + ( accuracy/ DERIVED_ATTRIBUTE_MULTIPLIER )  )/ 3 of "generic offensive attributes"
  - with their "generic offensive attributes", have them choose optimally between a mix of Strength
    and dexterity and accuracy (1 point of accuracy from the pool = 1*DERIVED_ATTRIBUTE_MULTIPLIER)
    to deal the most aveage damage per turn with their Attack action on a target dummy
    on that floor
  - do not allow their allocations to exceed average percentage of the pool the allocated attribute takes up.
    For example, plain accuracy may take up about 20% of the average offensive attribute pool, and str/dex take 40% each.
    Their hypothetical allocations into each attribute should not exceed those counts.
  - then add their expected available discretionary points * n/100 as optimally distributed for damage

BestImprovementEquipmentSolver
- drop all items on ground
- filter out dominated items (if exists seven +2 dex rings and one +1 dex ring, no one will want that +1 dex ring)
  - add them to the UnusedEquipment pile
- sort equipment slots in random order
- for each slot
  - for each item that fills that slot
    - for each party member
      - multiply equipment affix values by the configurable intensityMultiplier
        - to see what it would be like if a character was trying to use 
          "60% of equipment provided attributes for their goal"
      - measure current goal performance
        - for auto-attack damage this is "average damage on target dummy sampled over x attacks"
        - for basic spirit users this is "total spirit"
      - try on the item
      - record how much the goal performance increased
    - give the item to character who's goal performance increased the most
    - record that item as "tested: assigned to character x, with new GoalPerformanceScore"
    - if the item displaced a previously tested item
      - place it back in the pool for re-testing
    - after all items in this slot tested, check displaced items 
      - each item should have a GoalPerformanceScore change for each character that didn't initially get the item
      - any item they actually did get should also have a GoalPerformanceScore
      - assign the displaced item to the character it would increase GoalPerformanceScore the most for
        - if it displaces their item, put that item back in the re-check pool
        - if no character wants it, put it in the UnusedEquipment pile
- return the UnusedEquipment pile to the caller for sharding or exclusion from future testing
