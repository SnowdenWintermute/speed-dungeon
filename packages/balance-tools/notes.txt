Best equipment solver

- checks what equipment combinations from drops-so-far best meet current goal (slider from dps to survivability)
- allocates attributes to meet requirements for desired equipment
- knows the average speed of monsters on the floor
- allocates/equips to stay within a threshold of speed
    - going from below to above the avg enemy speed of the floor is highly rewarded
    - dropping below 1/2 the avg enemy speed of the floor is undesireable
- accounts for broken equipment

Party best-equipment solver, ran after each loot acquisition event
    - drop all items on the ground
    - find the best hand-held (mainhand/offhand) pair/item (if 2h) by goal
      - dps -> highest dps pair
      - mitigation -> best effective hp pair
    - determine if that set can be equipped
      - search the list for any items that give attributes allowing it to be equipped
    - if equippable, record the potential dps/effective hp score
    - if not, check next hand-held set permutation
    - after best option evaluated, check best option for the other two characters
    - select character that the set would best help
    - equip those items to the character
    - run the function again until all characters are wearing their best-available hand-held sets and supporting items
    - run a similar evaluation over remaining non-hand-held items
    - store all remaining items in character inventories
    - convert leftovers to shards using the rogue's ability

Party Damage Per Turn Optimized Equipment Solver
- The equipment pool includes all items the party has access to, including those equipped
  by characters. (they drop all items on the ground before re-assignment)
- From the pool, check if any equipment are strictly worse versions
  of other options that meet all character's potential desires. For example,
  if only one character wants 2h weapons, and there are two of the same 2h weapon
  where one has a strength affix, remove the vanilla one from consideration.
- In random order, characters pick their best equipment sets
  from the pool. Assuming 7 slots and 5 options per slot thats about 80000
  iterations for the first character, but due to weapon specialty restrictions
  it should be less.
- Once initial greedy set selection finishes, iterate through all potetial "swaps"
  in which we check if one character giving an item to another character would raise the
  party's total DPT
- Permute the possible orders in which characters select their best sets
- For each hypothetical party equipment setup, check the average damage each character
  would do against a target with "medium" evasion on the current dungeon floor
- From that, calculate the party's average "damage per character turn"
- Note if pick-order caused a great variance in damage-per-turn
- Use the best result from the pick-orders
